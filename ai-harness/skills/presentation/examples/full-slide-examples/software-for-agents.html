Agents and skills solve different problems

An agent is an execution context. A skill equips that context with a capability.

agent

Manages work

Chooses what to inspect, what to preserve in context, what to delegate, and when to act.

1Use another agent when isolation or parallel execution is the need.
skill

Provides capability

Adds workflow knowledge, tools, examples, templates, and verification to the main agent.

Software for agents is not one shape.

It can executeScripts, CLIs, services, and custom helpers.
