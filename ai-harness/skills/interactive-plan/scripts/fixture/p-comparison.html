In memory

State per process; resets on deploy.

Read path

const open = breaker.isOpen();

Failure mode

A restart forgets an open breaker and retries the gateway immediately.

Config

store = "memory" threshold = 5

Redis

Shared across processes; one more dependency.

Read path

const open = (await redis.get("breaker:gateway")) === "open";

Failure mode

Redis down means the breaker reads closed and every process retries at once.

Config

store = "redis" url = "redis://cache:6379"

Database row

Durable; a write per state change.

Read path

SELECT state FROM breakers WHERE name = 'gateway';

Failure mode

The database is already on the charge path; a slow query slows every check.

Config

store = "database" table = "breakers"
WhenProposed behavior

The breaker is open

The client returns a PaymentError with code breaker_open in under 5 ms and does not call the gateway.

Cooldown elapsed

One probe request goes through; success closes the breaker, failure reopens it for another cooldown.

Gateway times out

A timeout counts as a failure. The request fails after the configured 8 s, not the gateway's 60 s.

Gateway rejects the card

A 402 is not a failure for the breaker; the customer sees the decline and the breaker stays closed.
